# Roup frontend

React 19 and Vite application. From this directory, run `npm install`, then `npm run dev` for local development or `npm run build` for a production bundle.

Marketplace, order, listing, auction, and watchlist examples are stored in browser-local demo state. Authentication continues to use the existing Auth-Svc API via `VITE_AUTH_API_BASE_URL` (empty by default for Vite's `/api` proxy).
